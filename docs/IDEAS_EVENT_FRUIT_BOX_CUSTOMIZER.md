# Idea Note: Customizable Event & Meeting Fruit Box (Custom Fruit Box Builder)

> **Status:** Backlog / Idea Exploration (Do not implement in active code yet)  
> **Date Noted:** 2026-10-29  

---

## 1. Concept Overview
A self-customizable fruit box designed specifically for corporate meetings, seminars, and on-site events. Instead of fixed sets only, customers can interactively assemble their own box from a curated fruit catalog.

---

## 2. Pricing & Structure Model
- **Base Starting Price:** `฿65 THB / box`
- **Selection Capacity:** 3 to 5 fruit varieties per box
- **Fruit Cost Tiers:**
  - **Standard Thai Fruits (Base Cost = +฿0):** Included in the ฿65 base price (e.g., seasonal watermelon, guava, pineapple, dragon fruit, papaya, etc.)
  - **Premium / Imported Add-ons:** Variable extra cost depending on fruit type:
    - Tier 1: `+฿20` (e.g., green/red seedless grapes, kiwi)
    - Tier 2: `+฿25` (e.g., premium melon, strawberries)
    - Tier 3: `+฿30` (e.g., cherries, shine muscat, imported berries)

---

## 3. Benefits & Value Proposition
- **Fun & Interactive:** Enhances customer engagement on the website.
- **Budget Flexibility:** Corporate organizers can tailor boxes to meet exact per-head catering budgets (e.g., budget-conscious ฿65 box vs. VIP executive ฿115 box).
- **Dietary Control:** Allows clients to avoid certain fruits or pick specific favorites easily.
- **Clear LINE Order Handoff:** Selected fruits and calculated unit prices can automatically format into the LINE OA pre-order message.
